# Arcanea Agentic Swarm Ops Playbook

**For Us (Empire Building) + Adopters (Empowerment)**  
**Core Stack**: arcanea-orchestrator + Hermes profiles (arcanea) + Starlight SIS (Queen/memory/swarm) + 6-Pillar Guardians + GenCreator skills + MCP.

## Principles
- Sovereign first: Work on user/world repos via git worktrees.
- Lore-aware: Every agent loads Arcanea context (Luminors, Ten Gates, canon fidelity).
- Observable & Gated: Logs, evals, visual QA, ethics gates.
- Compounding: Memory + skills + evolution loops.
- Responsible: Attribution always, consent in standards, human oversight for sensitive.

## Architecture Overview
- **Orchestrator Layer**: arcanea-orchestrator (worktrees, sessions, swarms, dashboard :4200). Routes via arcanea-flow semantics.
- **Runtime Layer**: Hermes (profiles, MCP tools, skills, cron, kanban, delegation/gateway). Dedicated arcanea profile.
- **Intelligence Layer**: Starlight (memory, knowledge-tree, evals, sentinels). Starlight Queen as meta-orchestrator/sentinel for Arcanea.
- **Governance**: 6-Pillar Guardians (Strategy, Governance/Ethics, Talent, Technology, Data) + quality gates.
- **Creative Execution**: Studio router (canon-injected), world-sdk (genesis → evolve → render), publishing (author-os, claw).
- **Connectors**: MCP (Suno existing; build ComfyUI, GitHub, world ops, etc.).

## For Our Empire Ops
1. **Daily/Recurring**:
   - Starlight Queen /si cycles: Audit Arcanea repos, evolve docs/roadmap, visual QA.
   - Hermes cron: Nightly world health (validation, status-all), swarm health.
   - Kanban: Multi-agent boards for studio, worlds, partners, content.
2. **Swarm Deployment**:
   - Use delegate_task for parallel (e.g., router improvements + SDK + partner research).
   - Worktree per major task.
   - Load skills: agentic-orchestration, 6pillar, hermes-agent, starlight-queen.
3. **Hermes Arcanea Profile** (Flagship):
   - Pre-load lore context, world-sdk tools, studio dispatch, canon guardian.
   - MCP: suno + future ComfyUI/world.
   - Cron/kanban enabled.
4. **Guardians**:
   - 6pillar-factory to seed/evolve pillar profiles specialized for Arcanea (e.g., Tech-Guardian owns router/SDK).
5. **Evals & Improvement**:
   - multi-llm-arena for creative tasks.
   - Starlight evals for canon fidelity + output quality.
   - Patch skills post-success.

**Persistent Systems**: Memory, curator for skills, gateway for multi-platform.
